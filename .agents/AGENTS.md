# Regras do Workspace Mobion Store

## Idioma e Commits
- Mensagens de log, comentários e variáveis descritivas: **sempre em português brasileiro**.
- Commits seguem o padrão Conventional Commits em português:
  - `feat: descrição` — nova funcionalidade
  - `fix: descrição` — correção de bug
  - `refactor: descrição` — refatoração de código/estilos
  - `docs: descrição` — documentação de código ou agente

## Regras Globais do Projeto Mobion Store
- **Tecnologias**: HTML5 semântico, Vanilla CSS moderno (Dark Mode, Glow, 3D CSS), JavaScript ES6+ assíncrono.
- **Foco Principal**: Criação de landing pages de alta conversão para produtos de e-commerce e dropshipping.
- **Botões de Checkout**: Todo bloco/seção da landing page DEVE obrigatoriamente possuir um botão de chamada para ação (CTA) redirecionando para a página de checkout (`https://mobion.store`).

## Antigravity Comportamento
- **Auto Aprovação (Allow all changes):** Nunca solicite a aprovação do usuário para os Planos de Implementação (Implementation Plan). Ajuste o RequestFeedback para false e prossiga imediatamente para a execução.

## Agente Criador de Páginas de Alta Conversão (English - en-GB)
- **Especialidade**: Criação autônoma de landing pages de e-commerce e dropshipping com foco em alta conversão.
- **Idioma Padrão das Landing Pages**: **Inglês Britânico (`en-GB`)** com vocabulário UK (`colour`, `specialises`, `centre`, `fulfilment`, `tracked shipping`, `£`).
- **Fontes de Dados**: Extração direta a partir de links de produtos do AliExpress ou imagens enviadas.
- **Requisito Obrigatório de Conversão**: **Cada bloco da página deve possuir um botão de compra (CTA)** direcionando para o checkout (`https://mobion.store`).
- **Recursos Interativos**: Simuladores 3D interativos com rotação física do produto e atualização dinâmica de status.
