# HU63 - Documentação por Adolescente

## 1. Descrição e Especificação da HU

### Introdução
Este documento especifica a funcionalidade **"Documentação por Adolescente"**, pertencente ao módulo **Registros Pedagógicos**.
A funcionalidade permite ao usuário pesquisar documentos emitidos para adolescentes, consultar o histórico documental conforme filtros informados e emitir relatório consolidado em formato PDF contendo os documentos encontrados.

### História de Usuário
- **Como** usuário do módulo Registros Pedagógicos
- **Ao acessar** a funcionalidade "Documentação por Adolescente"
- **Quero** pesquisar e consultar documentos emitidos para adolescentes
- **Para** acompanhar o histórico documental e emitir relatórios para controle e acompanhamento pedagógico.

---

## 2. Regras de Negócio (RNs)

- **RN01**: O sistema deverá permitir a pesquisa utilizando os seguintes filtros: Região, Zona/Subregião, Centro, Módulo, Período de expedição inicial, Período de expedição final, Tipo de documento, Via e Status.
- **RN02**: Os campos Região, Zona/Subregião e Centro deverão recuperar as informações do Módulo Lotação.
- **RN03**: O campo Módulo deverá permitir selecionar os módulos existentes da Fundação CASA.
- **RN04**: O campo Tipo de Documento, recuperado do Módulo Adolescente, deverá listar somente as opções: **RG**, **CIN**, **CPF**, **Declaração Escolar** e **Histórico Escolar**.
- **RN05**: O campo Via deverá permitir selecionar: **1ª Via**, **2ª Via**, **Outras vias cadastradas**.
- **RN06**: O campo Status, recuperado do Módulo Adolescente, deverá listar somente as opções: **Providenciado**, **Apresentado**, **Atualizado** e **Em andamento**.
- **RN07**: Ao acionar o botão "Pesquisar", o sistema deverá apresentar os registros compatíveis com os filtros informados.
- **RN08**: Caso nenhum filtro seja informado, o sistema deverá apresentar **MSG01**.
- **RN09**: Caso não existam registros compatíveis com os filtros informados, o sistema deverá apresentar **MSG02**.
- **RN10**: O resultado da pesquisa deverá apresentar: Região, Zona/Subregião, Centro, Módulo, Período Inicial, Período Final, Tipo de Documento, Via, Status.
- **RN11**: A listagem deverá apresentar o total de registros encontrados.
- **RN12**: A listagem deverá possuir paginação com exibição de 10 registros por página.
- **RN13**: O botão "Gerar Relatório" deverá ficar disponível após a realização da pesquisa.
- **RN14**: Ao acionar o botão "Gerar Relatório", o sistema deverá gerar um relatório em formato PDF.
- **RN15**: O relatório deverá apresentar os filtros utilizados na pesquisa.
- **RN16**: O relatório deverá apresentar os adolescentes encontrados conforme os filtros aplicados.
- **RN17**: O relatório deverá apresentar os seguintes dados dos adolescentes: Nome, PT, Sexo, Idade, Status Documento, Data Última Ocorrência, Data Emissão (Solicitação).
- **RN18**: O título do relatório em PDF (removido a obrigatoriedade de formato rígido anterior conforme apontamento da área de negócios).
- **RN19**: Os registros do relatório deverão ser apresentados por sessão, considerando o documento e dentro das sessões, a ordem cronológica decrescente (da ocorrência mais recente para a mais antiga).
- **RN20**: O relatório deverá apresentar data e hora de emissão.
- **RN21**: O relatório deverá apresentar numeração de páginas.

### Mensagens ao Usuário
- **MSG01**: "Informe pelo menos um filtro para pesquisa."
- **MSG02**: "Nenhum registro encontrado para os filtros informados."
- **MSG03**: "Relatório gerado com sucesso."

## 3. Apontamentos e Alinhamento com a PO

- **Padrão de Pesquisa no Banco da Pedagogia (`TB_DOCUMENTO_ADOLESCENTE`)**:
  - Conforme alinhado com a Analista PO, a busca de documentos na tela `/Pedagogia/RegistrosPedagogicos/DocumentacaoAdolescente` pesquisa diretamente na tabela `TB_DOCUMENTO_ADOLESCENTE` do banco de dados da Pedagogia via API Backend (`PesquisarDocumentoAdolescenteQuery` / Dapper).
  - A emissão do relatório em PDF consome o endpoint `GET /api/v1/documentacao-adolescente/relatorio-pdf` da API Backend, que pesquisa os registros da `TB_DOCUMENTO_ADOLESCENTE` e gera o PDF via iText7.
